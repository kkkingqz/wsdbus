# Журнал решений

Решения приняты 2026-10-17 при планировании. «Пользователь» — решение
владельца. «Принято» — предложение, с которым владелец согласился.

Планы: **1** — [контракт и GNOME](plans/2026-10-17-core.md) (без Hyprland),
**2** — [стек Hyprland](plans/2026-10-17-hyprland.md).

| # | Решение | План | Кто |
|---|---|---|---|
| W1 | Hyprstack целиком не подключать. Плавающие окна делает собственный обработчик на Rust с модульной структурой; идеи Hyprstack и Omarchy — образец | 2 | пользователь |
| W2 | Плавающие окна в Hyprland нужны | 2 | пользователь |
| W3 | Общий API для wstouchbar, wswidgets и оконного демона, без дублирования логики | 1, 2 | пользователь |
| W4 | В контракте только факты и команды рабочего стола и состояние окон. Встраивание интерфейса, правила окон, звук и железо остаются в проектах | 1, 2 | принято |
| W5 | Яркость — необязательная возможность: её отдаёт поставщик GNOME | 1 | принято |
| W6 | Нормализация `app.id` — одно правило контракта с общими тестовыми случаями | 1, 2 | принято |
| W7 | Один репозиторий: контракт, клиент, поддельный поставщик, `ctl`, демон Hyprland и расширение GNOME | 1, 2 | принято |
| W8 | Название `wsdbus` | 1, 2 | пользователь |
| W9 | QML-потребители работают через `wsdbus-ctl` (`watch --json` и разовые команды), без моста и JSON-зеркала в поставщиках | 1, 2 | принято |
| W10 | wswidgets сначала берёт только `session.locked` и `appearance.scheme`; полный стиль кнопок остаётся в его адаптере | 1 | принято |
| W11 | Демон Hyprland — два модуля: `provider` всегда, `policy` по выбору | 2 | принято |
| W12 | Своего кода C++ нет. Заголовки окон — официальный hyprbars из hyprland-plugins | 2 | принято |
| W13 | Код Hyprstack (GPL) не копируется, берутся только идеи. Код Omarchy (MIT) можно заимствовать с указанием источника | 2 | принято |
| W14 | `ws-window` переходит на `wsdbus-ctl`; window-control после этого убирается. Перемещение, размер и геометрия окон в контракт v1 не входят | 1, 2 | принято |
| W15 | Window Monitor Pro заменяется контрактом: оно ставилось ради активного окна для wstouchbar | 1 | пользователь (назначение), принято |
| W16 | Факт `keyboard.layout` только для чтения. CapsLock, UA, LED и переключение раскладки остаются в `workstation-input-source` и `ws-input-source` | 1, 2 | принято |
| W17 | Расширение xremap остаётся: свой протокол, в Hyprland у xremap свой бэкенд. Расширения интерфейса GNOME не трогаются | 1 | принято |
| W18 | В GNOME модуля `policy` нет: окна плавающие, половины и четверти — Tiling Assistant, свёрнутые — Ubuntu Dock. Интерфейс окон нужен только в Hyprland | 1, 2 | принято |
| W19 | Плавающий режим задаётся для каждого рабочего стола; в конфигурации режим по умолчанию для каждого стола; отдельное сочетание меняет режим всех столов сразу | 2 | пользователь (из предложенных вариантов) |
| W20 | Доверие: изменяющие методы отклоняются для процессов в песочнице (Flatpak, Snap), остальные процессы пользователя допускаются; списка доверенных имён нет | 1, 2 | пользователь (из предложенных вариантов) |
| W21 | Лицензия MIT | 1, 2 | пользователь |
| W22 | План разделён на два: контракт и GNOME без Hyprland (1) и весь стек Hyprland (2) | 1, 2 | пользователь |
